# Lab Task 03 – JUnit Unit Testing

## Objective
The objective of this lab is to learn unit testing in Java using the JUnit 5 framework. This lab focuses on creating Java classes, writing unit tests for their methods, and verifying the results of automated test execution.

## Tasks Completed

### Task 1 – Temperature Converter
Implemented and tested temperature conversion methods:
- Celsius to Fahrenheit
- Fahrenheit to Celsius
- Celsius to Kelvin
- Round-trip conversion testing

### Task 2 – Bank Account Operations
Implemented and tested:
- Positive deposit
- Valid withdrawal
- Withdrawal beyond available balance
- Negative deposit exception

### Task 3 – String Utility
Implemented and tested a palindrome checker for:
- Normal palindrome
- Case-insensitive palindrome
- Non-palindrome
- Null input
- Empty string

### Task 4 – Simple Timer Utility
Implemented and tested:
- Normal elapsed-time calculation
- Boundary case
- Invalid input exception

### Task 5 – Shopping Cart
Implemented and tested:
- Adding items
- Removing items
- Clearing the cart
- Removing a non-existent item

## Test Results

## How to Run

1. Clone or download this repository.
2. Open the project in NetBeans IDE.
3. Make sure JDK and Maven dependencies are configured.
4. Run the project tests using **Test Project**.
5. View the results in the Test Results window.
